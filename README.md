## 📖 About the Project

Welcome to my **Python Crash Course** repository!

This repository documents my journey of learning Python through practical examples, code experiments, and personal notes. It covers fundamental programming concepts and gradually progresses toward more structured programming with functions, classes, and inheritance.

The code includes explanations and comments primarily in Uzbek, making the materials useful for Uzbek-speaking beginners who want to understand Python concepts step by step.

The repository also includes a small interactive shopping cart program that demonstrates how fundamental Python concepts can be combined into a practical console application.

### 🎯 Goals

- Build a strong foundation in Python programming.
- Understand fundamental data types and data structures.
- Practice conditional logic, loops, and functions.
- Learn the basics of object-oriented programming.
- Develop problem-solving skills through hands-on coding.
- Apply Python fundamentals in small projects.

## 🛒 Mini Project: Shopping Cart

The repository includes `shop_card.py`, a simple command-line shopping cart application.

### Features

- Add products to the shopping cart.
- Remove products from the cart.
- Display the current list of products.
- Navigate through a menu using user input.
- Exit the program when finished.

### Example

```text
Savatcha:
[]

Amallar:
1. Mahsulot qo'shish
2. Mahsulot o'chirish
3. Savatchani ko'rish
4. Chiqish
```

This project demonstrates how lists, loops, conditional statements, and user input can work together in a small interactive program.

## 🚀 Getting Started

### Prerequisites

- Python 3 installed on your computer.
- A code editor, such as VS Code or PyCharm, or a terminal.

No third-party Python packages are required for the basic examples shown in this repository.

### 1. Clone the repository

```bash
git clone https://github.com/AzamatErgashov/python_crash_book.git
```

### 2. Open the project directory

```bash
cd python_crash_book
```

### 3. Run a Python file

For example, run the shopping cart program:

```bash
python shop_card.py
```

Depending on your system, you may need to use `python3` instead:

```bash
python3 shop_card.py
```

You can also run individual learning files:

```bash
python part1.py
python part2.py
python part3.py
```

Run each file separately to explore its examples and observe the output.

## 💡 How to Learn from This Repository

1. Start with the first section and progress through the files.
2. Read the comments and examine the code examples.
3. Run the code and observe what happens.
4. Change values, test different inputs, and experiment with the examples.
5. Try writing your own solutions before looking at existing examples.
6. Use `shop_card.py` to practice combining fundamental programming concepts.

**Learning principle:** Don't just copy the code. Understand it, experiment with it, and try to explain how it works.
